# Frontend

Static COLM registrar portal. Open `index.html` through XAMPP or a local browser.

## Structure

- `index.html`: page markup and login form.
- `css/style.css`: login and portal styles.
- `js/script.js`: interface behavior and development-only demo sign-in.
- `assets/images/`: portal logo, registrar seal, and page background.

Demo credentials currently live in `js/script.js`; they are not production authentication.
